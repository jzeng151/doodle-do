# Doodle-Do

Doodle-Do is a local-first pixel-animation editor that pairs drawing tools with optional teaching.

## Toolbar

**Toolbar layout**:
The user's choice of which drawing-toolbar controls are visible. The available layouts are Essentials, Full, and Custom.
_Avoid_: Toolbar mode, toolbar preset

**Essentials layout**:
A curated reduced toolbar for users who want fewer visible choices.
_Avoid_: Minimal mode, beginner toolbar

**Full layout**:
The complete drawing toolbar with every group visible.
_Avoid_: Advanced mode, classic toolbar

**Custom layout**:
A toolbar whose tool buttons and control groups are chosen by the user.
_Avoid_: Personalized mode

**Toolbar preference**:
The user's selected toolbar layout and Custom layout choices, shared across projects.
_Avoid_: Project toolbar settings

## Teaching

**Tip**:
A brief, event-triggered note about animation craft that appears while the user works.
_Avoid_: Tutorial, tool help

**Tool lesson**:
A user-started guided task on the canvas that teaches one drawing tool and recognizes completion.
_Avoid_: Tip, tour, tooltip

**Layout chooser**:
The first-use visual comparison where a user selects Essentials, Full, or Custom.
_Avoid_: Onboarding tour
